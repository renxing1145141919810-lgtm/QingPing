# 清屏（QingPing）

Android广告辅助拦截实验项目。当前版本使用无障碍服务识别页面中明确标注的“跳过/关闭广告”控件，并记录成功点击次数。

## 构建
在GitHub Actions的Actions页面运行Android Debug APK工作流，成功后从Artifacts下载QingPing-debug-apk。

## 安装与启用
安装后进入系统设置，手动启用清屏无障碍服务。请只在知情并同意的设备上使用。不同应用界面差异较大，不能保证识别所有广告。

## 限制
- 不保证拦截所有开屏广告或误触跳转。
- 不执行不明确的点击，也不模拟全局返回键。
- Android系统和厂商后台策略可能停止服务。
- 当前为调试版本，尚未经过完整真机测试。
